!!! info "New: AquariusProxy 5.0 (beta)"

    The **5.0** pre-release is out on the launcher's `java.1.21.4` channel — boat autopilot, bubble-column traversal, KitMaker, and backported stability fixes, with PearlDrop / Enchanter / multi-leg ElytraPilot still in beta. See [**What's New in 5.0**](Whats-New.md).

!!! warning "Before you install"

    AquariusProxy runs on the **`java` release channel only** (the `.jar`, Java 21+) on **Windows, Ubuntu/Linux, or macOS**, and needs **at least 1 GB of RAM** (a 512 MB VPS is not enough). The native `linux` build and other platforms are **not tested or validated**. See [System Requirements](Setup.md#system-requirements).
